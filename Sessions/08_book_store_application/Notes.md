# Notes

### 1. OnChanges

Called when input data changes via the `@Input()` decorator.

### 2. OnDestroy

Triggered when the component is destroyed or removed.

### 3. OnInit

Executed when the component is initialized.

### 4. OnContentInit

Invoked after projected content is initialized (before the view initialization).

### 5. OnViewInit

Called after the component’s view has been fully initialized.
